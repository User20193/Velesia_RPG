# My 2D RPG Engine (C++ + Python)

Привет! Это твой личный игровой движок. Вся тяжелая работа (графика, окно) написана на **C++** (используется библиотека `Raylib`), а логика игры пишется на **Python**, что делает разработку очень быстрой и приятной.

## Структура проекта

* `src/` - Исходный код ядра на C++
* `game/` - Твоя игра на Python
  * `game/main.py` - Основной скрипт игры. Здесь ты пишешь игровую логику (передвижение, бои).
  * `game/assets/` - Папка для твоих картинок (в будущем и звуков). Сюда ты будешь складывать свои ассеты.

## Инструкция по сборке и запуску для Windows 10

Поскольку ядро написано на C++, его нужно один раз **скомпилировать** (превратить в код, понятный компьютеру), чтобы Python мог его использовать. Не пугайся, это делается буквально за пару кликов.

### Шаг 1: Установка необходимых программ

1. **Python:** Если у тебя еще нет Python, скачай его с [официального сайта](https://www.python.org/downloads/) (версия 3.8 или выше). *Важно:* при установке обязательно поставь галочку **"Add Python to PATH"**!
2. **Visual Studio C++ Build Tools:**
   * Скачай [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).
   * Запусти установщик, выбери карточку **"Разработка классических приложений на C++"** (Desktop development with C++) и нажми Установить. Это даст твоему компьютеру возможность понимать C++ код.
3. **CMake:** Это программа, которая настроит проект.
   * Скачай CMake с [официального сайта](https://cmake.org/download/) (ищи файл `cmake-X.X.X-windows-x86_64.msi`).
   * При установке выбери опцию **"Add CMake to the system PATH for all users"**.

### Шаг 2: Компиляция движка

Теперь, когда все программы установлены, давай соберем движок:

1. Открой папку с этим проектом.
2. Открой командную строку прямо в этой папке. (Проще всего нажать на адресную строку в папке, написать `cmd` и нажать Enter).
3. Введи по очереди следующие три команды и дождись выполнения каждой (первая команда может занять пару минут, так как она скачивает библиотеки из интернета):

```cmd
cmake -B build
cmake --build build --config Release
```

Если всё прошло успешно, в папке `game/` появится файл с названием вроде `engine.cp310-win_amd64.pyd` (это и есть твой C++ движок, готовый для работы с Python).

### Шаг 3: Запуск игры

1. Перейди в папку `game` в командной строке:
```cmd
cd game
```
2. Запусти игру через Python:
```cmd
python main.py
```

Откроется окно игры, где ты сможешь управлять красным квадратиком (это твой персонаж) с помощью клавиш WASD или стрелочек!

## Как добавить свои картинки?

Когда ты будешь готов заменить красный квадрат на своего персонажа:
1. Положи картинку (например, `hero.png`) в папку `game/assets/`.
2. Открой файл `game/main.py` в любом текстовом редакторе.
3. Найди строку `tex_mgr = eng.get_texture_manager()` и сразу под ней добавь:
   `tex_mgr.load_texture("hero", "assets/hero.png")`
4. В самом низу, где рисуется игрок (`eng.draw_rectangle(...)`), замени эту строку на:
   `tex_mgr.draw_texture("hero", player_x, player_y)`

Удачи в разработке твоей RPG!
